À quoi sert cet outil

Pièce centrale de l'indicateur 11 (Majeure) : trace l'évaluation des acquis bloc par bloc, compétence par compétence, indicateur par indicateur. Pour les formations certifiantes (Ind. 3) : la décision certificative est calculée automatiquement.

Workflow

  • Référentiel : saisir les blocs / compétences / indicateurs (à faire une fois par formation)
  • Évaluations : créer une fiche par bénéficiaire — cliquer sur le bouton détails pour évaluer
  • Synthèse : KPI session + matrice bénéf × bloc avec décisions auto

Échelle des niveaux

  • 0 — Non acquis : n'a pas atteint le niveau attendu
  • 1 — En cours : progresse mais partiellement
  • 2 — Acquis : maîtrise dans le cadre attendu
  • 3 — Maîtrisé/Expert : dépasse le niveau attendu

Décisions automatiques

  • ≥ 80 % : ✨ Mention
  • 66 – 79 % : ✓ Acquis (validé)
  • 50 – 65 % : ⚠ Partiellement acquis
  • < 50 % : ❌ Non acquis (reprise)
